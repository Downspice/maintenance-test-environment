# Commitment Request App

## Overview
The Commitment Request App is designed to streamline the process of submitting, querying, and managing commitment requests. The application features a user-friendly interface with tabbed navigation for easy access to different functionalities.

## Features
- **Commitment Request Tab**: 
  - A form to submit new commitment requests.
  - Fields include request type, commitment request number, description, date of request, notes, and an upload field for supporting documents.
  - Financials section with inputs for compensation, Capex, goods and services, and a calculated total.

- **Queried Request Tab**: 
  - A search input to filter requests.
  - Displays cards for each request with details such as request type, date, total, and a status indicator.

- **Completed Request Tab**: 
  - Similar to the Queried Request tab, but for completed requests.
  - Includes pagination controls and a search input.

## Installation
To get started with the Commitment Request App, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd commitment-request-app
   ```

3. Install the dependencies:
   ```
   npm install
   ```

## Usage
To run the application, use the following command:
```
npm start
```
This will start the development server and open the app in your default web browser.
